Paste this into the README of your GitHub profile repository after the project has been published to the `main` branch:

```markdown
## Income Growth Forecast

Upload an income spreadsheet to explore your earnings history, growth, and a trend-based forecast. Spreadsheet data is processed in the browser; forecasts are estimates, not guarantees.

[![Income Growth Forecast demo](https://raw.githubusercontent.com/menakavemula64-hue/income-growth-forecast/main/assets/income-growth-forecast-promo.gif)](https://github.com/menakavemula64-hue/income-growth-forecast)
```

GitHub displays the animated GIF inline. The image URL will work after the GIF is pushed to the public `income-growth-forecast` repository. For an interactive public website link, enable GitHub Pages for that repository and replace the link around the image with the published Pages URL. A profile README repository must have the same name as your GitHub username.
